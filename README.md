## FAQ

### What is XCutors?

XCutors is a curated collection of popular Roblox executor tools bundled together with a universal loader (xcutorsLoader) for convenient management on Windows desktop.

### Which executors are included in the pack?

The pack includes four executors: Volt, Synapse Z, Potassium, and Wave, all accessible through the universal xcutorsLoader interface.

### Is XCutors free to use?

Yes, XCutors is completely free to download and use. However, some individual executors included in the pack may have their own separate licensing or access requirements.

### What operating systems are supported?

XCutors is designed exclusively for Windows. It supports Windows 10 and Windows 11 (64-bit). macOS and Linux are not supported.

### How do I update the executors to the latest version?

You can check for updates directly through the xcutorsLoader interface, or download the newest release package from the GitHub Releases page and re-extract the files.

### Why is my anticomponent flagging the executor files?

Anticomponent software may flag executor tools because they use code injection techniques to interact with the Roblox process. You can add an exclusion for the XCutors folder in your anticomponent settings. Always download XCutors only from the official GitHub repository.

### Can I add my own custom Lua scripts?

Absolutely. You can load custom .lua files through the built-in script editor, drag and drop script files into the executor window, or paste code directly into the editor pane.

### The executor is not attaching to Roblox. What should I do?

Ensure you are running the executor as Administrator, that Roblox is fully loaded and you are in-game, and that your anticomponent is not blocking the process. Try restarting both the executor and Roblox if the issue persists.

### Does XCutors work with Roblox UWP (Microsoft Store) version?

Compatibility depends on the individual executor. The xcutorsLoader will indicate which executors support the standard Roblox Player and which also support the UWP version. The standard web-installed Roblox Player is recommended for best compatibility.
